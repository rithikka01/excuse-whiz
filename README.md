# 🤡 ExcuseGPT — Your Personal Excuse Engineer

> Pick your situation. Choose your vibe. Let the excuses begin.

**ExcuseGPT** is a playful, interactive web application that generates humorous excuses for everyday situations. Whether you're late to work, missed a deadline, skipped the gym, or forgot to reply to a message, ExcuseGPT has a creative excuse ready for you.

🔗 **Live Demo:** [Try ExcuseGPT](https://excuse-whiz.vercel.app)

## ✨ Features

- 🎭 **Multiple Situations** — Generate excuses for being late, missing deadlines, cancelling plans, skipping the gym, and forgetting to reply.
- 🎨 **Personality Modes** — Choose from Innocent, Corporate, Dramatic, and Unhinged.
- 🎲 **Random Excuses** — Discover a surprise excuse with one click.
- 🔄 **Regenerate Excuses** — Get another excuse whenever you want.
- 📋 **One-Click Copy** — Copy your favorite excuse to the clipboard.
- 📜 **Excuse History** — View recently generated excuses during your session.
- 📱 **Responsive Design** — Enjoy the experience on desktop and mobile.
- 🌌 **Playful UI** — Dark theme, purple gradients, neon accents, and interactive elements.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/rithikka01/excuse-whiz.git
   ```

2. Navigate to the project directory:

   ```bash
   cd excuse-whiz
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## 💡 How It Works

1. Select an everyday situation.
2. Choose your preferred personality.
3. Click **Generate My Excuse**.
4. Copy, regenerate, or explore your excuse history.

The current version uses predefined sample excuses and does not require an API key. A real generative AI integration can be added in a future version.
